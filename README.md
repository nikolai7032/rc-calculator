# rc-calculator
Калькулятор R и C — удобный инструмент для расчёта общего
сопротивления или ёмкости при параллельном и последовательном
соединении элементов. Создан для студентов, инженеров, радиолюбителей
и всех, кто работает с электроникой.

R un C kalkulators — ērts rīks kopējās
pretestības vai kapacitātes aprēķināšanai, ja elementi ir savienoti paralēli un secīgi.
Izstrādāts studentiem, inženieriem, radioamatieriem
un visiem, kas strādā ar elektroniku.

The R and C Calculator is a handy tool for calculating the total
resistance or capacitance in parallel and series
connections of components. It is designed for students, engineers, hobbyists,
and anyone who works with electronics.
